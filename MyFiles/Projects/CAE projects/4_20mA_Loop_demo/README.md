## Files in this Repository
- **Demo_GUI**: A tradeshow-ready browser-based GUI for explaining and showcasing the demo.
- **EV92J35A_Board_Design**: The Altium project, Gerber files, schematics, and BOM for the EV92J35A 4-20 mA transmitter board.
- **EV92J35A_Firmware**: The firmware for the PIC18F26Q71 MCU on the EV92J35A 4-20 mA transmitter board. Can be programmed using ICSP and a Microchip programmer.
- **PAC1711_RX_Firmware.X**: MPLAB X project containing the firmware for the PAC1711-based receiver. Requires a PAC1711 Click Board from mikroE, a PIC18F57Q43 Curiosity Nano board, and Curiosity Nano Base for Click Boards.
- **RX_GUI**: Python-based GUI for displaying the current received by the PAC1711-based receiver.
- **Demo User Guide Pressure Sensor with 4-20 mA MASTERs 26.pdf**: A comprehensive user guide describing how to set up the demo and explain it to clients.
